## [Unreleased]

### Added
- Initial release of Airworks - Build the Flow
- Core duct construction system with grid-based placement
- Airflow simulation using simplified physical model
- Multiple component types: straight ducts, corners, T-junctions, cross junctions, inlets, outlets, fans, valves
- Real-time airflow visualization with animated particles
- Component property editing
- Simulation controls (start, pause, reset, step)
- Undo/Redo functionality
- Save/Load system with local storage
- Zoom and pan camera controls
- Keyboard shortcuts
- Dark theme UI
- Blacksmith CI configuration for Windows/Linux builds
